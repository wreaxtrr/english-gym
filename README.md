# English Gym

Личный тренажёр английского от B1 до C1 / IELTS 8.0. Все упражнения построены на твоих темах: зал, МГТУ, общага, аналитика данных, программирование, собеседования. В первую очередь тренируются твои типичные ошибки, а не то, что ты уже знаешь.

Статический сайт без бэкенда и без сборки. Прогресс хранится в `localStorage`.

## Разделы

| Раздел | Что там |
|---|---|
| **Сегодня** | Тренировка дня (20–30 мин), слабые места, серия дней |
| **Карта** | Личные ошибки и темы по ступеням B1 → B2 → C1 с освоенностью каждой |
| **Письмо** | Свободное письмо с автопроверкой на твои типичные ошибки |
| **IELTS** | Speaking Part 1–3 и Writing Task 1–2: таймер, счётчик слов, критерии оценки |
| **Копилка** | Фразы, в которых ты ошибся, и незнакомые слова. Выгрузка в Quizlet |
| **Прогресс** | Статистика по темам, история, настройки, резервная копия |

## Тренировка дня

1. **Разминка**: 6–10 заданий из личных ошибок и уже пройденных тем. Выбор взвешен по слабости темы.
2. **Новая тема**: правило на русском с примерами и ловушками. При повторном показе правило свёрнуто.
3. **Подходы**: 7–14 заданий по новой теме, от простого к сложному (выбор → вставка → исправление → перевод), плюс 1–3 задания на повторение пройденного.
4. **Письмо**: ответ на вопрос в 3–5 предложений с разбором.
5. **Итог**: точность, как изменился «вес» тем, сколько ушло в копилку.

Ошибка в задании → это же задание возвращается в конце раздела («ещё раз»), фраза попадает в копилку, а тема — чаще в разминку. Незаконченную тренировку можно поставить на паузу.

## Типы заданий

- **Вставь пропущенное** — форма глагола, предлог, артикль, частица фразового глагола.
- **Выбери вариант** — клавиши 1–4.
- **Найди и исправь ошибку** — предложение уже вставлено в поле, его нужно поправить.
- **Переведи RU → EN** — принимаются разные верные варианты; если твой вариант верный, но его нет в списке, нажми «Мой вариант тоже верный».
- **Послушай** — диктант слова или фразы либо выбор услышанного слова (buckwheat / backwards). Озвучка встроена в браузер.
- **Напиши ответ** — 3–5 предложений либо IELTS-формат на 150–250 слов.

При проверке не важны регистр, пунктуация, сокращения (I'm = I am) и британское или американское написание (analyse = analyze). Опечатки в одну букву специально **не** засчитываются: именно так выглядят твои ошибки (-s, then/than, time/times).

## Адаптивность

**По заданиям**: интервальное повторение, 6 коробок с интервалами 0 → 1 → 3 → 7 → 16 → 35 дней. Верный ответ отправляет задание в следующую коробку, ошибка — в первую, и тогда задание вернётся завтра.

**По темам**: у каждой темы есть «освоенность» (0–100%), это скользящее среднее последних ответов. Личные ошибки стартуют с 35%, новые темы — с 0%. Вес темы в разминке:

```
вес = (1 − освоенность)^1.5 × 3  +  давность (до 0.5)  +  0.25 × заданий к повторению
если освоенность ≥ 85% и ответов ≥ 12 → вес × 0.25 (стабильно правильно — реже)
```

**Прохождение темы**: освоенность ≥ 75% и минимум 16 ответов. После этого включается следующая тема по карте, а пройденная уходит в пул повторения. Любую тему можно сделать текущей вручную или отметить как известную.

**Письмо** тоже влияет на адаптивность: каждая ошибка, найденная автопроверкой или отмеченная тобой при сверке с образцом, снижает освоенность своей темы.

## Автопроверка письма

Около 50 правил под твои ошибки: пропуск be, артикли (as a data analyst, the hardest), предлоги (at BMSTU, next year, for breakfast), -s у второго глагола, форма после would/must/did, will после after/when/if, can вместо привычки, кальки (we with Sasha, for get, own без my, explain me), ложные друзья (press/abs, course/year, strings of code), числа (800 thousand, more than, three times), than/then, орфография. Правила проверены на всех образцах и правильных ответах: ложных срабатываний на них нет.

Автопроверка ловит только известные шаблоны. Для полного разбора есть кнопка **«Промпт для проверки в ИИ»**: она копирует текст и готовую инструкцию для ChatGPT или Claude с твоими типичными ошибками, критериями IELTS и строками для Quizlet.

## Копилка → Quizlet

В копилку попадают:
- правильная фраза из задания, в котором ты ошибся;
- слова, которые ты отметил как незнакомые в теории;
- исправления из письменных ответов.

Выгрузка: «Скопировать» или «Скачать .txt» → в Quizlet «Создать» → «Импорт», разделитель «Tab», между карточками «Новая строка». Кнопка «Отметить как выгруженные» нужна, чтобы в следующий раз выгружать только новое.

## Содержание

- **Личные ошибки** (12 тем): be, артикли, предлоги, -s, форма после модальных, время ответа, can ≠ привычка, кальки, ложные друзья, числа, орфография, на слух.
- **B1 → B1+** (8 тем): Present Perfect, Past Continuous, модальные, условные 1–2, сравнительная степень, фразовые глаголы, связки, собеседование и проекты.
- **B1+ → B2 и B2 → C1** (21 тема в плане): пассив, Past Perfect, придаточные, герундий/инфинитив, условные 3 и wish, косвенная речь, коллокации, IELTS Task 1/2, инверсия, хеджирование, академическая лексика, перефразирование и другие. На карте они видны как «в разработке».
- **IELTS**: 20 заданий для Speaking Part 1–3 и Writing Task 1–2.

Всего 312 заданий.

## Публикация на GitHub Pages

1. Создай репозиторий (например, `english-gym`) и залей в него содержимое этой папки.
2. Settings → Pages → Build and deployment → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет на `https://<логин>.github.io/english-gym/`.

`.nojekyll` уже лежит в корне. Локально сайт открывается двойным кликом по `index.html`, сервер не нужен.

## Перенос прогресса

Прогресс живёт в браузере. «Прогресс» → «Скачать резервную копию» сохраняет JSON, а «Загрузить из файла» восстанавливает его на другом устройстве или в другом браузере.

## Как добавить задания и темы

```
index.html
styles.css
js/content-errors.js   личные ошибки
js/content-b1.js       темы ступени B1
js/content-roadmap.js  ступени и план тем B2/C1
js/content-ielts.js    задания IELTS
js/checker.js          сравнение ответов, diff, правила автопроверки письма
js/store.js            прогресс, интервальное повторение, копилка
js/engine.js           выбор темы, подбор заданий, план тренировки
js/tts.js              озвучка
js/app.js              интерфейс
```

Формат задания:

```js
{ t: "gap",    q: "I ___ to the gym four times this week.", h: "be", a: "have been", ex: "Пояснение", c: ["термин", "перевод для копилки"] }
{ t: "choice", q: "I'm ___ second-year student.", o: ["a", "the", "—"], a: 0, ex: "..." }
{ t: "fix",    q: "I study in BMSTU.", a: "I study at BMSTU.", ctx: "необязательный вопрос-контекст" }
{ t: "tr",     q: "Я тренируюсь в зале три раза в неделю.", a: "I {work out|train} at the gym {three|3} times a week." }
{ t: "listen", say: "internship", a: "internship", ru: "стажировка" }           // диктант
{ t: "listen", say: "I had buckwheat.", o: ["buckwheat", "backwards"], a: 0 }   // выбор на слух
{ t: "write",  q: "Вопрос", need: "Условие", model: "Образец", focus: ["n_pp"] }
```

В ответах `{a|b}` — один из вариантов, `[a|b]` — необязательная часть. Поле `c` — карточка для копилки; без него карточка соберётся из задания.

**Важно:** новые задания добавляй только в конец массива `items`. Номер задания — его id в прогрессе, и вставка в середину перепутает историю повторений.

Чтобы открыть тему из плана B2/C1, заполни у неё `theory` и `items` в формате `content-b1.js` (удобно вынести в `js/content-b2.js` и подключить в `index.html` перед `content-roadmap.js`, убрав тему из плана).

После изменений контента запусти `node tools/validate.js`. Скрипт проверит индексы вариантов, пропуски, что правильные ответы и образцы не вызывают срабатываний автопроверки и что неправильные предложения из заданий «исправь» не засчитываются как верные.
