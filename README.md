# English Gym

Тренажёр английского от B1 до C1 / IELTS 8.0. Одна дорожная карта из 37 уроков, в каждом теория на русском и задания на английском. Примеры — из жизни студента: универ, общага, зал, аналитика данных, программирование, собеседования.

Статический сайт без бэкенда и без сборки. Прогресс хранится в `localStorage`.

**Урок засчитан**, когда освоенность ≥ 75% и набралось 16 ответов. **Уже знаешь тему?** Открой урок и сдай тест: 8 заданий разных типов, для зачёта нужно 7 верных. Урок засчитается, и сразу откроется следующий. Можно и просто нажать «Засчитать без теста».

## Тренировка дня (20–30 мин)

1. **Разминка** — 7 заданий на повторение пройденных уроков; чем слабее урок, тем чаще. Пока ни один урок не пройден, разминки нет.
2. **Новая тема** — правило текущего урока. При повторном показе свёрнуто.
3. **Подходы** — 10 заданий по уроку, от простого к сложному, и 2 на повторение.
4. **Письмо** — ответ на вопрос с разбором.
5. **Итог** — точность, как изменилась освоенность, что ушло в копилку.

Ошибка → задание вернётся в конце раздела, фраза попадёт в копилку, а урок станет чаще появляться в повторении. Тренировку можно поставить на паузу. Длину (15 / 25 / 40 мин) можно сменить в «Прогрессе».

## Типы заданий

- **Вставь пропущенное** — форма глагола, предлог, артикль, частица.
- **Выбери вариант** — клавиши 1–4.
- **Найди и исправь ошибку** — предложение уже вставлено в поле.
- **Переведи RU → EN** — принимаются разные верные варианты; если твой верный, но его нет в списке, нажми «Мой вариант тоже верный».
- **Перепиши** — перефразирование по условию: в пассив, с инверсией, через существительное.
- **Послушай** — диктант или выбор услышанного слова (озвучка встроена в браузер).
- **Напиши ответ** — 3–5 предложений или IELTS-формат на 150–250 слов.

При проверке не важны регистр, пунктуация, сокращения (I'm = I am) и британское или американское написание. Опечатку в одну букву тренажёр не засчитывает сам: так выглядят потерянное -s и then/than. Если это и правда опечатка, засчитай кнопкой.

## Адаптивность

**По заданиям** — интервальное повторение: 0 → 1 → 3 → 7 → 16 → 35 дней. Верный ответ сдвигает задание дальше, ошибка возвращает его на завтра.

**По урокам** — освоенность 0–100% (скользящее среднее ответов). Вес урока в повторении:

```
вес = (1 − освоенность)^1.5 × 3  +  давность (до 0.5)  +  0.25 × заданий к повторению
освоенность ≥ 85% и ответов ≥ 12 → вес × 0.25
```

Письменные ответы тоже влияют: каждая найденная ошибка снижает освоенность своего урока.

## Письмо и автопроверка

Около 50 правил ловят частые ошибки русскоязычных: пропуск be, артикли, предлоги, -s в третьем лице, форма после would/did, will после when/if, кальки, ложные друзья, числа, than/then, орфография. Для уроков B2–C1 тренажёр показывает, сколько раз ты использовал нужную конструкцию (пассив, инверсию, хеджирование и т. д.), а также длину текста, разнообразие лексики и число связок.

Кнопка **«Промпт для проверки в ИИ»** копирует текст с готовой инструкцией для ChatGPT или Claude: разбор ошибок, исправленная версия, лексика B2–C1, оценка по критериям IELTS и строки для Quizlet.

## Копилка → Quizlet

«Скопировать» или «Скачать .txt» → в Quizlet «Создать» → «Импорт», разделитель «Tab», между карточками «Новая строка». «Отметить как выгруженные» — чтобы в следующий раз выгрузить только новое.

## Публикация на GitHub Pages

1. Создай репозиторий (например, `english-gym`) и залей в него содержимое этой папки.
2. Settings → Pages → Build and deployment → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет на `https://<логин>.github.io/english-gym/`.

Локально открывается двойным кликом по `index.html`.

## Перенос прогресса

«Прогресс» → «Скачать резервную копию» (JSON), на другом устройстве — «Загрузить из файла».

Импорт проверяет структуру файла и просит подтвердить замену. Перед импортом и сбросом сохраняется одна предыдущая копия: кнопка **«Копия до последней замены»** скачает её для восстановления через обычный импорт. Это локальная страховка, поэтому для переноса и защиты от очистки браузера скачивай JSON отдельно.

Незаконченные письменные ответы, введённый ответ в упражнении и результат его проверки сохраняются при паузе и обновлении страницы. Ошибка записи в браузер показывается отдельным предупреждением. Если прогресс изменён в другой вкладке, устаревшая вкладка останавливает запись: скачай её копию и обнови страницу.

Обновление совместимо с прежним форматом `v: 1` и ключом `english-gym-v1`. Идентификаторы уроков и заданий сохранены. Прогресс остаётся в том же браузере и на том же адресе сайта; автоматически между устройствами он не синхронизируется.

## Проверки для разработки

Без установки зависимостей (Node.js 20+):

```sh
node --test tests/store.test.js
node tools/validate.js
```

Тесты проверяют совместимость старого прогресса, импорт и резервную копию, ошибки хранилища и конфликт вкладок. Валидатор проверяет все 37 уроков и 624 задания и завершает работу с ошибкой при проблемах.

Для браузерных проверок:

```sh
npm install
npx playwright install chromium
npm run test:browser
```

Можно использовать установленный Edge, задав переменную окружения `PLAYWRIGHT_CHANNEL=msedge`. Тесты запускают локальный сервер и отдельный временный профиль: реальный учебный прогресс не используется. Проверяются пауза и перезагрузка, черновики, пересчёт исправленного текста, импорт, конфликт вкладок и мобильная верстка.

## Как добавлять задания

```
js/content-b1.js / content-b2.js / content-c1.js   уроки по уровням
js/content-roadmap.js   уровни карты
js/content-ielts.js     задания IELTS
js/checker.js           сравнение ответов, автопроверка письма
js/store.js             прогресс, интервальное повторение, копилка
js/engine.js            карта, подбор заданий, план тренировки, тесты
js/app.js               интерфейс
tools/validate.js       проверка контента
```

```js
{ t: "gap",    q: "I ___ to the gym four times this week.", h: "be", a: "have been", ex: "Пояснение", c: ["термин", "перевод для копилки"] }
{ t: "choice", q: "I'm ___ second-year student.", o: ["a", "the", "—"], a: 0 }
{ t: "fix",    q: "I study in BMSTU.", a: "I study at BMSTU." }
{ t: "tr",     q: "Я тренируюсь три раза в неделю.", a: "I {work out|train} {three|3} times a week." }
{ t: "rw",     q: "People say that BMSTU is prestigious.", h: "Начни с BMSTU is said…", a: "BMSTU is said to be prestigious." }
{ t: "listen", say: "internship", a: "internship", ru: "стажировка" }
{ t: "write",  q: "Вопрос", need: "Условие", model: "Образец", focus: ["b1_pp"] }
```

`{a|b}` — один из вариантов, `[a|b]` — необязательная часть. Новые задания добавляй **только в конец** `items`: номер задания — его id в истории повторений. После правок запусти `node tools/validate.js`.
